# Contributing

Thanks for considering contributing! This project is a small prototype so pull requests, issues, and feedback are welcome.

Guidelines:
- Please open an issue for new features or bugs before a big change.
- Use feature branches: `feature/<name>` or `fix/<bug>`.
- Small, focused PRs are preferred.
- Write tests for new functionality and add instructions for testing in PR.
- Keep the README updated with usage examples.

Style:
- Follow PEP8. We recommend using `black`/`ruff` in developer env.
- Use `pytest` for tests.

License:
- MIT by default unless otherwise specified.
